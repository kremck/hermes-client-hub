Client Hub Help

This page goes over use cases for Client Hub and clears up common questions.

Frequently asked questions

How do I connect my clients to everyone else's?

Under the "Data" tab, you have two options:

  • Load shared file - This replaces your local data with the shared file. Make sure to save your own copy first if you have unsaved changes you don't want to lose.
  • Merge shared file - This adds any new clients or users from the shared file without overwriting your current local records.
How do I add a new client?

Under "Quick Add", you can enter the client's information. To add campaigns and other details, you will need to navigate to the Clients or Reminders tab, click on the client, and add the ad being worked on.

The graphics team is able to attach the path to the proof files.

How do I update a client's information?

To update a client's information, navigate to the Clients or Reminders tab, click on the client, and edit the details as needed.
