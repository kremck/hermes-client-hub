How to use Client Hub

This guide reflects the current app behavior for login, client records, project tracking, and admin visibility.

1. Logging in and user roles

  • Use the login dropdown to choose a registered user.
  • Users are stored in the browser and may include Sales users and an Admin user.
  • The app recognizes the user role from each profile. A user with the role of admin can see all clients, all projects, and all ad records across the system.
  • Sales users are limited to their own assigned clients and their related activity.
What does the admin account do?

The admin account is meant to act as a dashboard-level user. It can review the full client list, view all project records, and inspect all ad work without being restricted to one person's assigned clients.

What happens if I accidentally delete the admin account?

If you accidentally delete the admin account, the app will automatically recreate it when the user list is loaded.

2. Adding and editing clients

How do I add a new client?

Use the Quick Add section to create a new client record quickly. The app will assign the current logged-in user as the client owner when available.

Once the client is created, you can open the client detail page to add contact information, relationships, notes, key dates, and ad campaigns.

How do I edit the details on a client?

Open the client from the directory or dashboard, then edit the fields shown on the detail page. This includes relationship, business type, contact info, notes, and similar record details.

When a client is deleted, the app removes the client record from the saved data and refreshes the directory/dashboard view.

3. Projects and ad tracking

How do I create a project?

Open the Projects area and add a project name, optional end date, and note. The project is then available to attach to ad records.

How are ads connected to a project?

From a client detail page, add an ad campaign and choose a project from the project dropdown if needed. Each ad can reference a project and keep its own status history.

On the project page, you can see which ads are linked to that project and which client they belong to.

How do I check ad status?

Each ad keeps a status history. The app shows the newest status first and displays related tracking and reminders in the dashboard and client detail views.

4. Dashboard and reminders

  • The dashboard summarizes visible clients for the logged-in user.
  • Key dates and follow-ups are grouped by date and shown in the reminder views.
  • Admin users see the full dataset for all clients, which makes dashboard summaries broader than a sales-only view.

Handling Data

Use the Data tools when you need to save, import, merge, or share client data across users or devices.

What happens when I import data?

Importing a file replaces the current local data with the imported JSON structure. It is a full local replacement, so use it carefully and make sure you are importing the correct file.

What happens when I export data?

Export saves the current client/project records to a JSON file so you can back up the data or send it to another user or device.

How do I merge data from another source?

Use the merge function with a saved file and compare it against the current app data. The app cross-checks client records and adds missing entries rather than replacing everything blindly.

This is useful for combining client lists from coworkers or a shared copy without losing the current local work.

How are users managed?

The app stores registered users locally. New users can be added from the user management area and assigned the default Sales role unless they are explicitly created as admin.

Admin access is enforced by the role value, and the app ensures an admin user is present in the list if it is missing.
