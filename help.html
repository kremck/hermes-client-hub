How to use Client Hub

This area covers the main flow for adding, reviewing, and updating client work in the app.

Getting started

  • Open the app from the main dashboard and choose the tab that matches the task you need.
  • Use Quick Add for new leads or simple entries.
  • To add new projects, such as Best of Mac 2026, navigate to the Add Project tab.
  • Open an existing client to add campaigns, reminders, and follow-up notes.

Common tasks

How do I add a new client?

Under "Quick Add", enter the client details. To add campaigns and other project information, open the client from the Clients or Reminders tab and update the record there.

Users can attach proof file paths from the client record.

To edit the client's details, click the client, and edit the details as needed.

Handling Data

Use the Data tab when you need to share or merge client information across users or devices.

How do I connect my clients to everyone else's?

Under the "Data" tab, you have three options:

  • Export file - This exports the current data you have in your project. It does not effect your current data.
  • Import file - Imports data from a saved JSON file. This will overwrite your current data on the program.
I am confused on how to use the Data tab.
  • Shared Folder - This is where you can merge your clients into the main file, as well as pull everyone else's clients. This is so other team members can access your clients and attach proofs for each ad / campaign.
  • Save File - This downloads the most concurrent client list, which includes both you and other colleague's client data and campaign data. This is to back up your data and be able to merge with the main folder.
  • Merge Shared File - You first choose your most recent save file (ends in .json), and after selecting it, make sure that you have a shared folder chosen. When you press "Merge file", it will take your uploaded file and cross reference to see if it needs to add new clients.
